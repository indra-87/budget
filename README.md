# 가계부 · 카드 실적

물품 구매 기록 + 신용카드 적립 한도 관리용 개인 웹앱. 빌드 없이 GitHub Pages에 올려서 쓰는 정적 사이트이고, 데이터는 Supabase에 저장합니다.

## 기능
- **입력**: 날짜 · 내역 · 금액 · 결제수단 · 사용처 · 비고. 사용처는 칩 선택 또는 직접 입력(과거 입력값 자동완성).
- **카드별 예상 적립**: 금액/사용처를 넣는 순간 카드 3장의 예상 적립과 한도 초과 경고를 보여주고, 누르면 그 카드로 선택됩니다.
- **적립 구분 자동 추천**: 사용처 키워드로 영역(쇼핑/주유/배달 등)을 추천하고, 직접 바꿀 수 있습니다.
- **내역**: 전체 누적 기록 검색(예: "생수" → 최저가·구매처·평균), 결제수단/기간 필터, 수정·삭제, CSV 내보내기.
- **카드 실적**: 월별 적립 합계, 통합 한도/영역 한도 진행 막대, 남은 결제 가능액, 건별 상세.
- **설정**: 주유 추정 단가, 마일 가치(기본 1마일=20원), 실적 기간 시작일(기본 매월 1일~말일), 자주 쓰는 사용처.

`js/config.js`의 값을 비우면 **데모 모드**(이 브라우저에만 저장)로 동작하니, 바로 열어서 써볼 수 있어요.

## 설정 현황
- **Supabase**: `Vibe coding` 프로젝트에 `gb_transactions`, `gb_settings` 테이블 생성 완료 (RLS: 로그인한 본인 행만 접근). 스키마는 `supabase/schema.sql`.
- **접속 키**: `js/config.js`에 입력 완료. publishable 키는 공개돼도 되는 키입니다.

### 처음 한 번 해야 할 일
1. Supabase → **Authentication → Users → Add user → Create new user**: 이메일/비밀번호 입력, *Auto Confirm User* 체크
2. Supabase → **Authentication → Sign In / Providers**: *Allow new users to sign up* 끄기 (나만 쓰도록)
3. GitHub 저장소 → **Settings → Pages**: Source *Deploy from a branch*, `main` / `/ (root)` → Save
4. `https://indra-87.github.io/budget/` 접속 후 로그인

## 적립 계산 규칙 (`js/cards.js`)
| 카드 | 규칙 |
|---|---|
| 신한 하이포인트 | 일반 2%, 쇼핑(롯데·현대백화점, 롯데마트, 이마트, 홈플러스, 토이저러스, CJ온스타일)·해외 5%, 주유(S-OIL·현대오일뱅크) L당 60P — 월 주유 20만원까지, 초과분은 2%. 통합 월 5만P |
| 쏠 플랜+ | 기본 1.5%, 주유(SK·GS)/온라인쇼핑(쿠팡·SSG·무신사·29CM)/배달(땡겨요·요기요·배민·쿠팡이츠) 5%. 영역별 월 30만원, 월 누적이 30만원에 도달하게 만드는 결제는 건 전체가 적립 제외(기본적립 포함), 이후 그 영역 결제도 계속 제외 (예: 29만원 후 9,000원 적립 / 10,000원 제외). 통합 월 6만원 |
| 삼성 앤마일리지 | 1천원당 1마일(건별 반올림), 추가적립처(백화점·주유·커피·편의점·택시) +1마일, 추가적립 월 2,000마일 한도(초과 시 기본적립만) |

**주유 리터 문제**: 하이포인트로 주유할 때 영수증의 리터(또는 리터당 단가)를 넣으면 정확히 계산하고, 비워두면 설정의 추정 단가(기본 1,650원/L)로 리터를 추정합니다. 추정치는 `(추정)` 표시가 붙어요.

테스트: `node tests/cards.test.mjs`
